APM 车窗按键模拟

第 2 版把模拟口从 1 路扩到 4 路，按“同一时刻只按一路”的要求复用一套电阻阵：4 个光耦继电器把公共节点分别接到 4 个接口，译码器保证任何时候最多接通一路。每路接口侧都有回读，所以任何一路都能做按键学习。

4 路共用一套 13 位电阻阵，硬件保证同一时刻只接通一路
2 个主控引脚改动，和第 1 版相同：PG2、PC2_C；PC3_C 仍空着
63 个器件其中 4 个默认不贴；237 个引脚，53 个新网络
23.9 mV200–4600 mV 每 200 mV 的最差误差：1% 电阻随机抽样，每路串联电阻 5–17 Ω 并已自动标定

  • PG2 经 Q808B 反相成 CH_EN_N，同时控制 U806 的 1G 和 U807 的 E。主控复位、上电或 HardFault 时 PG2 被 R814 拉低：U801 复位，电阻阵全关，4 个继电器全断。
  • 运行时总有一路接在公共节点上。电阻阵不下拉时，这一路只多了 400 kΩ 回读负载，对 APM 的影响约 0.5%。
  • 换通道时，固件先把电阻阵切到高阻，再改 CH_A0/CH_A1，然后等 5 ms。TLP176AM 断开最长 0.5 ms，接通最长 3 ms，天然先断后通。
  • 选中后用 0 Ω 直通档量一次接口电压，算出这一路的 PTC + 继电器串联电阻，之后按这个值求解。没有这一步，最差误差约 38 mV。

和第 1 版相比改了什么

  1. 1 路扩到 4 路。J801 从 2 脚换成 8 脚。原来接口侧的 F801、D801 和 300 kΩ 分压电阻，变成每路一套（F801–F804、D801–D804、R815–R818）。
  2. 每路加一个光耦继电器 TLP176AM。关断耐压 60 V，导通电阻最大 2 Ω，LED 由 U806 直接驱动。
  3. 回读改由 4 选 1 模拟开关选通。分压上臂留在各路接口侧，下臂 R819 和 C802 共用，所以选中哪一路，PC2_C 就读到哪一路接口的真实电压，包括原车开关接着时的电压。
  4. 电阻阵 12 位加到 13 位（b12 = 100 Ω），用掉 U801 的 P15。P16、P17 做通道地址。
  5. 使能改由 PG2 反相得到（Q808B + R824），不再占用 U801 的引脚。
  6. 每路预留一个空闲电阻位（R827–R830，默认不贴）。如果某车型的 APM 把开路判成故障，可以在这里贴上原车开关空闲时的阻值。贴了之后，这一路的被动学习读数会偏。

固件对接

// U801 TCA9539 @ 0x74，I2C4 (PD12/PD13)
// 输出寄存器 0x02：P00–P07 = b0–b7
// 输出寄存器 0x03：P10–P13 = b8–b11
//   P14 = SHORT，P15 = b12，P16 = CH_A0，P17 = CH_A1
// 初始化顺序不变：先写输出 0，再设方向

// 选通道 k (0–3)
winsim_set_hiz();                 // 先断开电阻阵
out1 = (out1 & 0x3F) | (k << 6);
i2c_write(0x74, 0x03, out1);
delay_ms(5);                      // 继电器接通 ≤ 3 ms
// 标定串联电阻
v_open  = adc();                  // 高阻
set_short(1); v_s = adc(); set_short(0);
r_series = 2200 * v_s / (v_open - v_s);

// 被动学习：不下拉，只读 WS_ADC
// 控制字 13 位，查找表 8192 项（32 KB）

PCB 摆放

  • J801 放在 J401/J402 同一侧板边，D801–D804、F801–F804 紧挨 J801。
  • R815–R818 尽量靠近各自的 PTC 前端，WS_S1–WS_S4 到 U807 的走线远离电阻阵和继电器的输出线。
  • U802–U805 排成一列，4 个输出端汇到一条短的 WS_NODE。继电器输入、输出两侧按 5 mm 爬电距离留空。
  • R819、C802 贴近 U301 第 28 脚；C803、C804 贴近各自芯片的 VCC 脚。
  • J801 的 4 个 GND 用短而宽的线就近接地平面，整块电路远离 U202、U201 的开关节点。
