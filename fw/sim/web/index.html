GROUPED CYCLIC SEND

按 ID 分组循环 两路独立运行，按列表顺序循环

启用 / 发送槽每轮次数同 ID 间隔 ms单 ID 总周期 ms

每个 ID 按间隔发送指定次数；从首帧起等待到“单 ID 总周期”后，切换到下一组。只有 ID 或标准/扩展格式不同时叠加“不同 ID 间隔”。列表末尾返回第一组持续循环，直到停止。默认时间为周期 100 ms、同 ID 间隔 10 ms、不同 ID 间隔 10 ms；次数较多时总周期自动加长到合法值。恢复默认只修改时间，不修改 ID、数据、次数和启用选择。

MESSAGE DATABASE

向模拟 SD 卡放入数据库 设备在屏幕内选帧和加入发送槽

支持 Vector DBC 和可识别的 BUSMASTER CAN 数据库文本 DBF。其他工具的 DBF 若格式不同会明确提示。文件放入卡后，在设备屏幕点“数据库选帧”操作。这里只模拟复制文件，不设置发送通道或参数。本地每份数据库最多256帧，超过限制会拒绝且不截断。解析使用本机 canmatrix，不上传文件到外部服务。

RECORDING SESSION

录制命名与新会话

不需要输入固定格式，前缀后自动加入时间与会话序号，例如 路试A_20261026-153000_00000008.log。前缀最多 18 个 UTF-8 字节；停止录制后会在本机弹出保存命名键盘，也可在文件管理中修改完整文件名（最多 47 字节，保留 .log 或 .txt 后缀）。时间无效时显示 NOTIME。

REC / R 短按开始，再短按停止。文件关闭后弹出命名键盘，保存或保留默认名后即可开始下一次录制。

匹配规则：(报文 ID & 掩码) = (匹配 ID & 掩码)。筛选只影响屏幕，录制继续保留全部所选通道的数据。设备上长按 OK 也可设置。

发送文件保存完整报文列表、数据与循环参数。电脑只负责把统一模板放入模拟 SD；在本机选中文件后直接载入手动编辑页，替换文件所含通道的配置，不会自动发送。

单路填写模板两路示例JSON 格式说明

每路固定 4 个槽，未用槽设 enabled=false。支持单路或两路方案，最多 16 个文件；同名文件保留。文件实际保存在本机模拟 SD 目录，重启后仍可读取。
